# Design instructions for this repository

When creating or editing a slide deck, an HTML presentation, a course module, or a teaching visual for «ИИ для бизнеса», **read and follow**:

- .agents/skills/ai-breakfast-course-design/SKILL.md
- .agents/skills/ai-breakfast-course-design/assets/tokens.css
- .agents/skills/ai-breakfast-course-design/references/slide-recipes.md

index.html is the immutable reference presentation unless the user explicitly asks to edit it. New course material should be implemented separately and reuse the design system: 1920×1080, dark editorial layout, Playfair Display / Inter Tight / JetBrains Mono, chartreuse accent #C9FF3D, square cards and restrained typography. The content and old branding of AI Breakfast are **not** the course template.

This repository holds the canonical design skill. Other course repositories should copy the skill folder and/or reference this source explicitly.
